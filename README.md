# ⚡ Bloody Lite

Сверхлегковесная кроссплатформенная альтернатива официальному софту **Bloody WorkShop** для мышей A4Tech Bloody, написанная на **Rust**.

Поддерживает **Windows** (10/11) и **Linux** (X11 / Wayland). Потребляет **~15 МБ RAM** вместо **~280 МБ** и работает без фонового мусора, служб и лишних модулей.

## 🎯 Возможности

- **Отображение и настройка DPI:**
  - Быстрый выбор популярных пресетов: `800`, `1000`, `1200`, `1600`, `3200`.
  - Плавный слайдер для точной настройки от `100` до `3200` DPI.
  - Мгновенное применение чувствительности в системе (Win32 API на Windows / xinput & libinput на Linux).
- **Переназначение боковых кнопок (Mouse 4 и Mouse 5):**
  - Поддержка назначения **любой клавиши клавиатуры** (буквы, цифры, F1-F12, Space, Enter, Escape, стрелки и др.).
  - Режим «Записи клавиши» в один клик.
  - Кнопка быстрого сброса на дефолт (Назад / Вперёд).
  - Нулевая задержка (0 ms latency):
    - **На Windows:** низкоуровневый системный хук (`WH_MOUSE_LL`) + `SendInput`.
    - **На Linux:** чтение событий ядра через `evdev` (`/dev/input/event*`) + виртуальное устройство ввода `uinput`.
- **Автоопределение оборудования:**
  - Сканирует USB HID устройства и определяет подключенную мышь A4Tech Bloody (VID `0x09DA`).
- **Автосохранение:**
  - Настройки сохраняются в компактный `bloody_config.json`.

## 🐧 Использование на Linux

### Права доступа
Для перехвата боковых кнопок мыши и эмуляции клавиатуры через `/dev/uinput` пользователю необходим доступ к группе `input`. 
Выполните один раз в терминале:
```bash
sudo usermod -a -G input $USER
```
*(После этого перезайдите в систему, чтобы применились права)*

### Сборка и запуск на Linux
```bash
# Установка зависимостей сборки (Debian/Ubuntu):
sudo apt install build-essential libudev-dev pkg-config

# Сборка и запуск:
cargo run --release
```

## 📊 Сравнение с Bloody WorkShop

| Параметр | Bloody WorkShop | Bloody Lite (Rust) |
| :--- | :--- | :--- |
| **Поддержка платформ** | Только Windows | **Windows + Linux** |
| **Потребление RAM** | ~280 МБ | **~15 МБ** |
| **Количество процессов** | 1 большой монолит | **1 легковесный процесс** |
| **Фоновые службы** | Да (проверка обновлений, реклама) | **Нет** |
| **Скорость запуска** | 3–6 секунд | **Мгновенно (< 0.5 с)** |
| **Стек** | C++Builder / VCL 32-bit | **Rust + egui + Win32/evdev** |
